# The Last Verse — Music

The songs for [The Last Verse](https://github.com/freak618/the-last-verse). The game's web versions (Cloudflare, GitHub Pages and itch.io) load the songs from this repo's GitHub Pages site:

`https://freak618.github.io/the-last-verse-music/music/<song>.mp3`

To add a song, put the mp3 in `music/` and add a line for it to `TRACKS` in the game's `index.html`.
